# 动效预设收尾设计

[English](presets-design.en.md)

日期：2026-11-08。范围：继续完成工作区已有的 Ping、Heart、Orbit 预设和晃动阈值改动。

## 1. 关键裁决

三个新预设共用现有声明式图层渲染器；上次有效的用户自定义文档与当前活动预设分开保存。
预设选择不能改变自定义解析失败时的回退对象。

## 2. 依据

代码检查：未提交改动已包含三个枚举值、manifest 选项及 `presets.h` 文档。
现有 `start()` 在线程建立消息队列前返回，紧接着的初始样式消息可能丢失。
轨道的 -0.6 倍速扫描使用已取模的周期进度，每过一周期便跳回起点。
这些是代码路径分析；实际验证结果单独记录。

## 3. 架构

保留协议线程、鼠标钩子线程、浮层线程。启动浮层时等待窗口和消息队列就绪；窗口创建失败返回失败。
预设注册表提供校验后的不可变文档，通过现有样式消息传递；投递失败和退出时回收消息内存。
保留现有设置键和四种内置效果，不增加依赖。

## 4. 核心逻辑

设置仍使用已有的 80 px、6 次换向、400 ms、1000 px/s 草案默认值。
纯逻辑测试验证模拟轨迹，不能据此宣称真人误触发率。
周期性半径与透明度使用取模后的进度；扫描角度使用累计周期，负速度的尾迹落在运动方向后方。

## 5. 交互

设置下拉框共八项：ring、waves、halo、radar、ping、heart、orbit、custom。
Ping/Heart/Orbit 周期分别为 1100/1400/1600 ms。默认效果为心跳；升级保留已保存的选择。
`mouse` 命令和动作 id 保持既有契约。
诊断显示选择的预设、有效图层数和周期；自定义失败区分“保留用户文档”和“回退圆环”。
设计预览中的彗尾、聚光灯、图钉等概念仍不是可用效果。

## 6. 权限、数据、隐私

沿用 `ui` 权限。预设为编译内置数据，无网络、无额外文件访问。
测试使用独立数据目录，结束后关闭其进程并清理目录；不修改正在使用的插件安装或用户配置。

## 7. 失败矩阵

| 条件 | 处理 |
|---|---|
| 自定义 JSON 非法 | 保留上次有效用户文档；没有历史时画圆环 |
| 自定义 JSON 清空 | 清除用户文档并使用圆环 |
| 内置或预设切换后再输入非法 JSON | 回退对象仍是用户文档，不是预设 |
| 预设文档无效 | 记录警告，使用圆环 |
| 未知或仅规划的效果 id | 使用 ring |
| 浮层窗口创建失败 | 启动返回失败，手动触发保留重试路径 |
| 样式消息投递失败或退出时未处理 | 回收堆对象 |

## 8. 交付清单

实现与回归测试、中英文 README、v0.4.4 变更说明、本设计文档、真实动效截图与验证记录。
用户已确认将默认效果改为心跳并发布 v0.4.4；主分支 CI 通过后推送标签，由 release workflow 构建发布包。

## 9. 分层测试

| 层 | 验证内容 |
|---|---|
| L0 | manifest 下拉框与实现集合一致，双语标签、运行时默认值、包内文件完整性 |
| L1 | 注册表查询、预设解析、模拟手势、非整数扫描连续性和尾迹方向 |
| L2 | JSON-RPC 初始化、动态切换、自定义跨样式回退、查询无副作用、实际窗口及超时 |
| L3 | wsbench + WinShunPluginHost 真实加载，每个预设的查询、诊断和 showNow |
| L4 | 真人晃动手感、多显示器、不同 DPI 和提权窗口需人工复测 |
| L5 | 从干净提交构建发布包，核对远端附件、SHA256、标签；不给出真人标定结论 |

## 10. 诚实笔记
