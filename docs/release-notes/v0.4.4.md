# v0.4.4

## 下载 · Download

使用本版本 Release 附件 `ra9fael.findmouse-0.4.4.wsplugin` 与旁边的 `.sha256` 文件。
Win顺 0.22.0 或更新版本：设置 → 插件 → 已安装 → 添加插件 → 压缩包。
Download the package and checksum from this release; install through
Settings → Plugins → Installed → Add plugin → Archive (.zip / .wsplugin).

## 新功能 · What's new

- 默认效果改为心跳，1400 ms 双环动画；新增声呐和轨道，共八个效果选项。
- Heartbeat is now the default, with a 1400 ms double-ring animation. Ping and Orbit
  join the existing effects for eight choices. Saved effect selections survive upgrades.
- 升级保留已保存的选择；想切换心跳可在“动效样式”中选择。

## 改进与修复 · Improvements and fixes

- 修复启动时样式丢失、自定义 JSON 回退串用预设、反向扫描跨周期跳变与尾迹方向。
- Fixed dropped startup settings, preset contamination of custom-style fallback,
  fractional-speed sweep resets and reverse-trail direction.
- 晃动默认阈值为 400 ms 内 6 次换向、80 px 行程、1000 px/s；可按设备调整。
- Gesture defaults: six reversals in 400 ms, 80 px stroke and 1000 px/s gate.
- 本地通过 178 项逻辑/配置检查、77 项集成断言及真实宿主默认心跳加载。
- Local validation: 178 logic/config checks, 77 integration assertions and default
  Heartbeat loading through the actual Win顺 plugin host.

## 插件库 · Plugin library

本版本通过作者仓库的 GitHub Release 分发。官方插件库尚未收录此插件，需从附件安装。
This release is distributed from the author's GitHub repository. The community index
does not currently list the plugin; install the release archive directly.

真人误触发率、多屏 DPI、独占全屏与提权窗口仍需人工验证。
Physical false-positive rates, mixed DPI, exclusive fullscreen and elevated windows remain unverified.
